# Creative Studio Migration Note — 2026-09-14

## Compatibility

- Existing canvas JSON and `.varian`/`.vca` packages remain readable. No document schema migration is required for this release slice.
- New local plugin registrations are stored under the optional `ccs_plugin_registry` preference key. Existing installations start with an empty registry and keep all existing documents unchanged.
- Plugin runtime counters are intentionally transient. Reloading the registry preserves registration state and approved permissions, but resets in-memory quota windows and storage reservations.

## Import behavior

- PDF import now creates page frames, literal text nodes, basic rectangles and line/cubic vector paths, plus embedded JPEG image assets when the document exposes a basic translation/scale CTM.
- PPTX import now creates embedded raster image assets from safe `ppt/slides/_rels` relationships and maps their EMU geometry to image nodes.
- Import remains intentionally loss-aware. Font metrics, transforms, transparency, advanced vector styling, PDF annotations/forms, PPTX themes/masters/tables/charts/animations, linked media, and unsupported image filters remain in the loss report.
- Invalid or unsupported documents continue to become auditable `fileCard` attachments instead of being silently dropped.

## Media behavior

- Native video proxy encoding is process-backed through `ffmpeg` when available on `PATH`.
- Missing encoders, unsupported targets, timeout, cancellation, and codec failures return explicit unavailable/failed states. Source bytes are never presented as an encoded proxy.
- iOS decoder validation, native codec bundling, and production collaboration/plugin/billing/observability services remain external release gates.

## User action

Review the import loss report before applying a lossy document. Keep the original source available when exact PDF/PPTX fidelity, forms, annotations, themes, or animation timing must be preserved.
