# Creative Studio UI Design-System Inventory

Status: **in progress**. This is an auditable inventory, not a claim that every listed surface has been visually verified or fully migrated.

## Completion criteria

The migration is complete only when all of these are true:

1. Every app-owned route, page, dialog, panel, and reusable UI component in `lib/app/` and `lib/features/` is listed below (including nested UI directories) and reviewed against Material 3, `Mix`, `AppTokens`, `AppResponsive`, `AppSpacing`, `AppRadius`, `AppBorder`, `AppControlSize`, and `Ui*` conventions.
2. Every app-owned explicit style/geometry literal is either replaced by an exact semantically equivalent existing token/style, or has a documented reason to remain. Authored/user payload rendering, document/canvas/chart/drawing/model/media geometry, metadata/data cells, and third-party/vendor controls are not chrome and remain unchanged.
3. Each changed surface has a focused local fixture verifying relevant layout/semantic/theme behavior and preservation of user/content data. Protected production routes use isolated local fixtures only.
4. Every router entry has its production route branch exercised locally or a specific documented reason and safe verification boundary; gated authenticated branches (including meeting screens) may be verified only with isolated local page fixtures, not by starting live sessions. No production project, account, backend, or collaboration data is accessed.
5. The changed Dart targets format and analyze cleanly; focused tests pass serially. App-wide test/runtime and visual verification scope is recorded, including any unavailable targets.
6. The source inventory, test inventory, migration note, and actual code agree. No unreviewed app-owned UI file remains before the goal can be completed.

## Shared foundations

- `lib/main.dart`: GoRouter registry, MaterialApp.router, theme/Mix/accessibility wiring.
- `lib/app/theme.dart`: `AppTokens`, `AppSpacing`, `AppRadius`, `AppBorder`, `AppControlSize`, Mix tokens/styles, Material 3 theme.
- `lib/app/responsive.dart`: breakpoints and responsive layout/constraint helpers.
- `lib/app/widgets/ui_primitives.dart`: shared `Ui*` primitives.
- `test/app/design_system_test.dart`, `test/app/responsive_contract_test.dart`, `test/widgets/ui_button_layout_test.dart`: shared foundations' focused contract coverage.
